# Asterra

Large-scale fantasy RTS in Unity — territory warfare, faction identity, commander-led armies, and a world that changes with player choices.

**Core loop:** Battle → Capture Territory → Gather Resources → Upgrade Army → Make Choices → Change World

## Tech stack

| Area | Choice |
|------|--------|
| Engine | Unity |
| VCS | Unity VCS (Plastic SCM) + this GitHub mirror for docs/planning |
| Multiplayer | Netcode for GameObjects + Unity Relay/Lobby |
| 3D | Blender (imported) |
| Platform | Steam |
| CI/Build | Unity Cloud Build |
| Analytics | Unity Analytics |

## Status

Foundations in progress. Architecture and scaffolding will land after scale targets (unit count, map size, factions) are confirmed — see open questions in the project discussion / first PR.

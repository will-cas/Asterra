# Demo controls (Mac-first)

## Pre-match (offline)
On play, pick **Your Faction**, **Enemy Faction**, and **Map** (Twin Keeps / River Crossing), then **Start Skirmish**.

## Economy loop
1. **Click your keep** → **Train Builder** (or **T**)
2. **Select builder(s)** → **RMB** a gold/timber node to **gather** (toast: Gathering...)
3. **Select builder** → **B** (or Build Barracks) → green ghost → **click** to place (toast: Building ordered)
4. Builder must be near the site (red ghost = too far / off-map)
5. **Click producer** → train **Soldier / Archer / Cavalry / Siege** (queues up to 3)
6. **RMB ground** with a building selected → set **rally** point

You start with 1 builder already. Extra gold/timber nodes sit near both bases plus the center (or river band on River Crossing).

## Pointer
| Input | Action |
|-------|--------|
| **Click** unit | Select |
| **Drag** | Box-select units |
| **Click** keep / producer | Select building (train panel) |
| **⇧ / ⌘ + click** | Add / toggle units |
| **B** (builder selected) | Enter place mode |
| **Click** (place mode) | Confirm building |
| **Esc / right-click** | Cancel place mode |
| **A** then **click ground** | Attack-move (Esc / miss cancels arm) |
| **Right-click** resource (builders) | Gather |
| **Right-click** ground (building selected) | Set rally |
| **Right-click** / Ctrl-click / two-finger click | Move or attack |
| **T** | Train default from selected building (keep → builder) |
| **X** | Cancel production on selected building |

## Production panel
When a building is selected (bottom-left):
- Keep: **Train Builder**
- Producer: **Train Soldier / Archer / Cavalry / Siege**
- Shows production **%**, **queue count**, **Cancel Prod**
- Hint: **RMB set rally**

## HUD feedback
- Top-center toast for attack-move arm, gather, building ordered
- Selection line: **Selected N** (builders vs combat when available)
- Hint: **A then click = attack-move**

## Cursors
| Cursor | Meaning |
|--------|---------|
| Arrow | Select |
| Green cross | Move order ready |
| Red X | Attack / attack-move armed |
| Amber pick | Gather (builders over resource) |
| Hammer | Valid build site |
| Red circle | Invalid build site |
| House+ | Building selected (train / rally) |

## Camera
| Input | Action |
|-------|--------|
| **WASD** / **arrows** / screen edge | Pan |
| **Scroll** | Zoom |
| **Click minimap** (bottom-right) | Pan camera to that point |

## Hotkeys
| Key | Order |
|-----|--------|
| **C** | March to capture center |
| **U** | Buy faction upgrade |
| **A** | Arm attack-move (then click ground) |
| **R** | Select all owned units |
| **X** | Cancel selected building production |

## Maps
| Map | Layout |
|-----|--------|
| Twin Keeps | Keeps on west/east (x ±350), center territory |
| River Crossing | Keeps at (-300,-220) / (300,220); resources along z≈0 river + near bases |

## Map / fog
- Light rim marks playable edge; black void beyond
- Fog of war hides unseen enemies
- Minimap: white = yours, red = revealed enemies, yellow/brown = resources

## Win / lose
- Destroy the enemy **keep**, or hold center territory **90s**
